# Yaadhum Oorae

A React and TypeScript landing page for Yaadhum Oorae, a creative studio offering video editing, reels, motion graphics, graphic design, and content support.

## Getting Started

Requirements:

- Node.js 18 or newer
- npm

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will provide the local URL in the terminal.

## Scripts

- `npm run dev` - Start the Vite development server.
- `npm run build` - Type-check and create a production build.
- `npm run lint` - Run ESLint.
- `npm run preview` - Preview the production build locally.

## Project Structure

```text
src/
  App.tsx                       Page composition
  index.css                    Global styles and design tokens
  components/
    sections/                  Page sections
    ui/                        Shared UI components
  assets/                      Local images and other assets
```

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Framer Motion

## Content and Configuration

Update the section components in `src/components/sections/` to change page content. Design colors and typography tokens are defined in `src/index.css`.
